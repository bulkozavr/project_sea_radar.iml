# Sea Radar

## Стек

- Node.js 24
- Next.js App Router
- React
- TypeScript 6.x, strict

## Команды

- `npm install` — установить зависимости
- `npm run dev` — запустить приложение на `http://localhost:3000`
- `npm run build` — собрать приложение
- `npm run start` — запустить production-сборку

## Границы текущей недели

Только каркас приложения. Не добавлять карту, суда, движение, карточки, сервер, внешние источники данных и тестовую инфраструктуру.
